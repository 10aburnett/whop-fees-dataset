# Whop seller fees (snapshot, 27 October 2026)

A small, dated table of the seller fees Whop publishes on its official fees page (https://docs.whop.com/fees), copied by hand on 27 October 2026. It is meant for creators comparing what they keep from a sale, and for anyone tracking how Whop's pricing changes over time. Each new snapshot is added as a new dated file; old files are never edited.

## Columns
- `category`: Whop's own grouping (Payments, Payouts, Fraud and security, Revenue optimization)
- `fee`: the fee as Whop names it
- `percent`: percentage of the transaction or payout (blank if not published as one rate)
- `fixed_usd`: fixed amount in US dollars
- `charged_per`: what the fee is charged on
- `condition`: when it applies
- `source_url`, `checked_on`: where and when the row was read

## Notes
- Whop states this pricing applies to new merchants signing up today; enterprise pricing differs.
- Whop also mentions a platform fee on some sales but publishes no rate, so it is not in the table.
- Example: a $100 domestic card sale with every optional add-on on and tax collected costs 6% + $0.30 in fees (Whop's own worked example).
